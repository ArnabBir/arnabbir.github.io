    TOPIC 59 / 64 · Sockets: Internet Domains

    Address resolution returns candidates

    A program assumes the first DNS result is reachable and fails despite another working address.

    ConceptAPI contractWorked tracePracticeSources

    The underlying idea

    Hostnames, numeric addresses, ports, and connected sockets are different layers. getaddrinfo produces candidate socket addresses for requested constraints. Resolution can block and returns its own error codes. IPv4 and IPv6 support, dual-stack defaults, and address selection vary with deployment.

    Contract and implementation boundary

    Set hints deliberately, iterate candidates, create the matching family/type/protocol socket, and close failed attempts. freeaddrinfo releases the list. Use gai_strerror for getaddrinfo failures rather than blindly reading errno. A nonblocking connect returning EINPROGRESS needs readiness plus SO_ERROR inspection.

    Contract references: getaddrinfo.3 · connect.2 · getsockopt.2. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    A writable socket after connect is not sufficient evidence of success. Assuming IPv6 listeners always accept IPv4 breaks on different IPV6_V6ONLY policies. Hardcoding sockaddr sizes loses family-specific length information.

    Worked reasoning trace

    Assumptions: Two resolved address candidates; first connection fails.

    1. Starting state

      One candidate socket was allocated.

    2. Operation

      Close the failed socket and try the next within an overall deadline.

    3. Expected observation

      Successful resolution did not guarantee reachability of the first candidate.

    Tradeoff: Multiple candidates improve reachability but need latency budgeting.

    This is a hand-authored prediction, not captured runtime output.

    Original practice problem

    Resolve localhost with numeric service 8080 and inspect each candidate without exposing a public listener. Sketch a bounded overall connection deadline across candidates rather than giving every address an unlimited wait.
