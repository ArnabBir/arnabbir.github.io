    TOPIC 12 / 64 · System and Process Information

    Observing a moving process

    A monitoring script reads /proc/PID and finds inconsistent values across files.

    ConceptAPI contractWorked tracePracticeSources

    The underlying idea

    procfs presents kernel state through file-like interfaces. A sequence of reads is not one global transaction: the process can allocate, exit, or exec between observations. Namespaces and permission checks affect visibility. A PID directory is not an immortal handle to a workload.

    Contract and implementation boundary

    Read bounded data, parse documented fields, and tolerate disappearing files. /proc/self refers to the reader itself. /proc/PID/fd exposes descriptor links subject to permissions; maps describes address mappings, not necessarily resident memory.

    Contract references: proc.5 · proc_pid_stat.5. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    Splitting /proc/PID/stat on spaces is unsafe because the parenthesized command name can contain spaces. Assuming every machine exposes the same fields or unrestricted process information makes diagnostics fragile.

    Worked reasoning trace

    Assumptions: Target process may exit between observations.

    1. Starting state

      A status read succeeds for PID P.

    2. Operation

      The target exits before maps is opened.

    3. Expected observation

      ENOENT is a lifecycle race, not evidence that the first read was fabricated.

    Tradeoff: Cheap snapshots are useful, but correlated monitoring needs timestamps and uncertainty.

    This is a hand-authored prediction, not captured runtime output.

    Original practice problem

    Inspect /proc/self/status and maps from a small helper, then compare with /proc of a short-lived child. Classify ENOENT after child exit as a lifecycle observation rather than a corrupt filesystem.

    Check your understanding

    Do two sequential procfs reads form a consistent process snapshot?

    Explain the answer

    No. State may change between reads; label the observation window.
