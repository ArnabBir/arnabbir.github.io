    TOPIC 43 / 64 · Interprocess Communication Overview

    Choose an IPC contract before an API

    Two processes share a memory region but disagree about whether a job is complete.

    ConceptAPI contractWorked tracePracticeSources

    The underlying idea

    Communication needs a data format, an ownership rule, a notification mechanism, and a failure policy. A pipe transports bytes through the kernel; shared memory exposes storage directly but supplies no application protocol. Message queues preserve message boundaries at the cost of bounded queue resources. Locality and lifetime often matter more than raw throughput.

    Contract and implementation boundary

    Write down maximum payload size, who may produce and consume, whether ordering is required, and what happens when a peer disappears. File descriptors are process-local handles; System V identifiers and POSIX names have different lookup and removal rules. No IPC primitive makes a multi-step business operation exactly once by itself.

    Contract references: pipe.7 · sysvipc.7 · shm_overview.7. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    A shared ready flag without synchronization is not a safe publication protocol. A queue that can grow faster than it drains is a memory or availability failure waiting to happen. A successful send can mean accepted locally, not processed remotely.

    Worked reasoning trace

    Assumptions: A 32-byte job must survive a producer restart without duplicate business effects.

    1. Starting state

      A local send succeeds.

    2. Operation

      Producer crashes before recording acknowledgement.

    3. Expected observation

      Transport success alone cannot decide whether retry is safe; use operation identity and reconciliation.

    Tradeoff: A simpler byte channel can suffice if the application supplies the missing protocol.

    This is a hand-authored prediction, not captured runtime output.

    Original practice problem

    Compare a 32-byte job sent through a pipe, a message queue, and a shared slot. For each, specify framing, synchronization, capacity, shutdown, and how an abandoned job is detected. Pick the simplest mechanism that meets the contract.
