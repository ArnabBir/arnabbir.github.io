    TOPIC 8 / 64 · Users and Groups

    Identity databases are services

    A username lookup unexpectedly stalls a request path.

    ConceptAPI contractWorked tracePracticeSources

    The underlying idea

    Numeric user and group IDs are kernel credentials. Human-readable names come from databases accessed through libc and NSS, potentially including network services. Reading /etc/passwd directly does not reproduce the configured lookup policy. A missing user and a lookup error are different outcomes.

    Contract and implementation boundary

    getpwnam_r uses caller-provided storage and a result pointer. A zero return with a NULL result means no matching entry; a nonzero return is an error number. ERANGE means the supplied buffer was too small. Bound growth and copy only fields whose lifetime you understand.

    Contract references: getpwnam.3 · getgrnam.3 · nsswitch.conf.5. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    Caching a pointer returned by a non-reentrant lookup can expose overwritten static storage. Assuming every account has a local password-file entry breaks managed environments. A primary group is not the complete supplementary-group set.

    Worked reasoning trace

    Assumptions: NSS lookup succeeds operationally but the name is absent.

    1. Starting state

      Caller owns a result pointer and a bounded buffer.

    2. Operation

      getpwnam_r returns zero and result is NULL.

    3. Expected observation

      Report not found, without dereferencing result.

    Tradeoff: System policy-aware lookup is broader than local parsing but can involve remote latency.

    This is a hand-authored prediction, not captured runtime output.

    Original practice problem

    Look up the current numeric UID with getpwuid_r and compare it with a deliberately nonexistent name. Report not-found separately from failure; do not require access to shadow-password data.

    getpwnam_r returns 0 and sets result to NULL. What does this mean?
