    TOPIC 45 / 64 · Introduction to System V IPC

    System V IPC objects outlive ordinary handles

    A restarted service finds an IPC object left by its previous process.

    ConceptAPI contractWorked tracePracticeSources

    The underlying idea

    System V queues, semaphore sets, and shared-memory segments are kernel objects identified by integer IDs. Keys help locate objects; they are not private ownership tokens. Objects can persist after a creator exits. IPC namespaces limit visibility but do not eliminate cleanup design.

    Contract and implementation boundary

    Use IPC_CREAT with IPC_EXCL when the program must know it created a fresh object. IPC_PRIVATE requests a new object; it does not disable permission checks. ftok can collide, so a derived key is not a unique identity. IPC_RMID removal semantics differ between queues, semaphore sets, and attached shared-memory segments.

    Contract references: sysvipc.7 · ipc.2 · ftok.3. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    Blindly reinitializing an existing object can corrupt a live peer's state. Blindly deleting everything listed by ipcs can disrupt unrelated applications. Store a protocol version and define one responsible owner.

    Worked reasoning trace

    Assumptions: Two creators use the same System V key with IPC_CREAT|IPC_EXCL.

    1. Starting state

      No object exists initially.

    2. Operation

      One creation wins before the other.

    3. Expected observation

      The loser receives EEXIST rather than authority to initialize the winner's object.

    Tradeoff: Persistent objects survive process restarts but need explicit recovery and removal.

    This is a hand-authored prediction, not captured runtime output.

    Original practice problem

    Sketch a create-or-attach handshake with a creator-only initialization stage. Classify EEXIST, permission failure, and removal during use. If experimenting, use IPC_PRIVATE and remove only the exact object you created.
