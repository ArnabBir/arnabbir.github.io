Chapter 03 — System Programming Concepts

Every interaction between user-space code and the kernel passes through exactly one gate: the system call interface. This chapter dissects the mechanics of that gate—how the CPU transitions from user mode to kernel mode via SYSCALL/INT 0x80, how the C library wraps raw syscalls into ergonomic functions, and how the kernel reports errors back through the errno contract.

Mastering this chapter means understanding: (1) every kernel service requires a syscall—there is no other path, (2) errno must be captured immediately after failure, (3) POSIX type aliases (pid_t, size_t, off_t) exist to decouple your code from platform-specific widths, and (4) robust error handling is not optional—it is the difference between production code and a toy.

Invariant
System calls are the ONLY way to request kernel services — every I/O, every fork, every signal delivery passes through the syscall gate.
Gotcha
errno is thread-local but ONLY valid immediately after a failed call; any intervening syscall or library function may overwrite it — save it to a local variable first.
Debugging
strace -c gives a syscall histogram showing counts and time; strace -e trace=file filters to file-related operations only.

Mental model

Internalize these bullets. If you can explain them clearly, you can debug most real-world incidents in this area.
  • Syscall mechanism: User code loads a syscall number into %eax/%rax and arguments into registers (%rdi, %rsi, %rdx, %r10, %r8, %r9 on x86-64), then executes the SYSCALL instruction (or legacy INT 0x80). The CPU switches to ring 0, the kernel dispatches via sys_call_table[nr], and returns the result in %rax.
  • errno as thread-local integer: On failure, the glibc wrapper stores -(kernel return value) into the thread-local errno and returns −1. errno is never set on success — it retains its previous value, so checking it without first checking the return value is a bug.
  • POSIX type aliases: Types like pid_t, size_t, ssize_t, off_t, and mode_t abstract away platform-specific widths. Using int instead of pid_t compiles today but breaks when assumptions change.
  • Library wrappers add convenience: stdio adds buffering over raw read/write; strtol parses integers with error detection that raw syscalls don't provide. The wrapper is not the syscall — know when you need to bypass it.
  • The −1 return convention: Most syscalls return −1 on error and set errno. The canonical pattern is: if (func(...) == -1) { saved = errno; /* handle */ }. Use strerror(errno) or perror() for human-readable messages.
  • Robust error-handling code: Production code checks every syscall return, saves errno before any other call, logs the operation + inputs + error string, and decides whether to retry (EINTR/EAGAIN) or abort.

Edge cases & invariants

This is where production bugs live. Expand each panel and treat the bullets as test cases.
When −1 is a valid return value
  • lseek() can legitimately return −1 as a file offset (rare but possible on some filesystems). The correct pattern: set errno = 0 before the call, then check if (ret == -1 && errno != 0).
  • sysconf() returns −1 for both errors and "no limit" — you must check whether errno was set to distinguish the two cases.
  • pathconf(), fpathconf() follow the same pattern: −1 without errno change means indeterminate, −1 with errno means error.
  • General rule: whenever a function documents −1 as both error and valid value, clear errno before calling and inspect it after.
Thread safety of errno
  • errno is implemented via thread-local storage (TLS): #define errno (*__errno_location()) on glibc. Each thread has its own copy.
  • Signal handlers share the thread's errno. An async-signal-safe handler must save and restore errno: int saved = errno; /* handler work */ errno = saved;
  • Functions documented as async-signal-safe (AS-safe) in signal-safety(7) are the only ones safe to call in signal handlers. Most stdio functions are NOT AS-safe.
  • In multithreaded code, strerror() uses a static buffer and is not thread-safe — use strerror_r() (POSIX) or strerror_l().
Type width portability (_FILE_OFFSET_BITS, LFS)
  • On 32-bit Linux, off_t defaults to 32 bits, limiting files to 2 GiB. Compile with -D_FILE_OFFSET_BITS=64 to get 64-bit off_t transparently (Large File Support).
  • With LFS, glibc rewrites open → open64, lseek → lseek64, etc. at the preprocessor level. Your source code stays unchanged.
  • On 64-bit systems, off_t is natively 64 bits — the macro is a no-op but harmless to include for portability.
  • ino_t, blkcnt_t are also affected by LFS. Always define _FILE_OFFSET_BITS=64 in your build system, not per-file.
  • Mixing translation units with different _FILE_OFFSET_BITS causes silent ABI incompatibility — struct layouts change.

Code patterns (C / POSIX)

Robust error-handling wrappers for open/read/write following the err_exit pattern from TLPI. 
/* err_exit pattern: robust syscall wrappers (TLPI ch03 style) */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <errno.h>
#include <unistd.h>
#include <fcntl.h>

static void err_exit(const char *msg) {
    fprintf(stderr, "%s: %s\n", msg, strerror(errno));
    exit(EXIT_FAILURE);
}

static int xopen(const char *path, int flags, mode_t mode) {
    int fd = open(path, flags | O_CLOEXEC, mode);
    if (fd == -1)
        err_exit(path);  /* includes path in message */
    return fd;
}

/* Loop until all bytes are written (handles short writes + EINTR) */
static void xwrite_all(int fd, const void *buf, size_t len) {
    const char *p = buf;
    while (len > 0) {
        ssize_t n = write(fd, p, len);
        if (n == -1) {
            if (errno == EINTR) continue;  /* interrupted; retry */
            err_exit("write");
        }
        p   += n;
        len -= (size_t)n;
    }
}

/* Loop until buf is full or EOF (handles short reads + EINTR) */
static ssize_t xread_all(int fd, void *buf, size_t len) {
    char *p = buf;
    size_t total = 0;
    while (total < len) {
        ssize_t n = read(fd, p, len - total);
        if (n == -1) {
            if (errno == EINTR) continue;
            err_exit("read");
        }
        if (n == 0) break;  /* EOF */
        p     += n;
        total += (size_t)n;
    }
    return (ssize_t)total;
}

Production checklist

If you are shipping code in this area, try to satisfy each checklist item explicitly.
  • Every syscall return value is checked; errno is saved to a local variable before any other call.
  • Error messages include the operation name, inputs (path, fd, flags), and strerror(saved_errno).
  • EINTR is retried in read/write loops; EAGAIN is handled for non-blocking fds.
  • All POSIX types are used correctly: ssize_t for read/write returns, off_t for offsets, pid_t for PIDs.
  • Build system defines _FILE_OFFSET_BITS=64 globally for large file support on 32-bit targets.
  • Signal handlers save and restore errno; only AS-safe functions are called inside handlers.
  • strace -f -o trace.log ./program is used to verify actual syscall behavior matches expectations.
