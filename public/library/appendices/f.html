    The underlying idea

    A useful solution states the starting state, legal transitions, and observation point. For this companion's descriptor problem, ordinary dup shares the offset but clears the new descriptor's close-on-exec bit. Serialized writes AB then CD through those aliases produce ABCD. A fresh open instead starts with its own offset and can overwrite.

    Contract and implementation boundary

    For this companion's signal problem, block SIGUSR1, generate it three times while it remains pending, then synchronously accept it: one standard pending instance is consumed. For the queue problem, priorities 1,3,3 produce the two priority-3 messages in FIFO order before the priority-1 message. These are independently authored exercises, not solutions to a book's exercises.

    Contract references: dup.2 · signal.7 · pipe.7. Check the documented return convention and platform notes before using an interface.

    Where reasoning goes wrong

    For the close problem, replacing client-active-close with server-active-close moves the ordinary TIME_WAIT endpoint to the server. For the pipe problem, an empty buffer plus a retained writer is not EOF. For the edge-trigger problem, reading three of eight bytes leaves five bytes without necessarily producing another edge.
