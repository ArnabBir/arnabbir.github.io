    Ten bounded C labs

    Small, independently written experiments for Linux. These sources are not book examples. Run as an ordinary user in a private working directory.

    Download common.h beside the C source. Use a C11 compiler and Linux libc headers. All commands below are Linux commands. A watchdog ends an unexpectedly blocked experiment; timing is not a scheduling guarantee.

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread descriptors.c -o descriptors
timeout 5s ./descriptors

    Replace descriptors with the selected lab name. Exit 0 means its internal checks passed. A nonzero exit or timeout needs investigation; expected observations below are predictions, not a claim of a Linux run. No root, network listeners, or kernel configuration changes are required.

    Shared offset, separate descriptor flags

    Duplicate a close-on-exec descriptor, serialize two writes, and compare a zero-count read with a real read.

    Download descriptors.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread descriptors.c -o descriptors
timeout 5s ./descriptors

    Expected: ABCD with shared offset four; original CLOEXEC set and duplicate clear. Zero-count read leaves data available.

    Change one condition: Replace dup with a separate open before unlinking. Predict whether the second write overwrites. Restore immediate unlink after both opens succeed.

    Cleanup and assumptions: One tiny mkstemp file, unlinked immediately; both descriptors close. Serialized regular-file operations, no durability claim.

    Coalescing while blocked

    Block SIGUSR1 before generating three instances, synchronously accept one, then probe for another without waiting.

    Download signals.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread signals.c -o signals
timeout 5s ./signals

    Expected: One SIGUSR1 accepted, then EAGAIN. The program never unblocks an unconsumed default-terminate SIGUSR1.

    Change one condition: Explain how a real-time signal and sigqueue would change counting, queue limits, and payload handling before implementing a bounded variant.

    Cleanup and assumptions: Single-threaded process; signals target only itself. Original mask restored. Requires Linux sigtimedwait.

    Copy, exit, reap

    Change a child-local variable, return it through _exit, and decode the wait status in the parent.

    Download processes.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread processes.c -o processes
timeout 5s ./processes

    Expected: Parent local remains 7; child exits with 9; waitpid reaps exactly that child.

    Change one condition: Add an unlinked file descriptor before fork and compare shared file offset with the private C variable.

    Cleanup and assumptions: One child, no recursive fork. Parent handles interrupted wait. Child runs no inherited stdio cleanup.

    A bounded synchronized counter

    Two joined workers each increment a counter 1,000 times under a mutex.

    Download threads.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread threads.c -o threads
timeout 5s ./threads

    Expected: Counter is exactly 2,000 after both joins. Thread scheduling order is unspecified.

    Change one condition: Move independent work outside the critical section and explain why the shared read-modify-write must remain protected. Do not use a data race as a valid benchmark.

    Cleanup and assumptions: Two threads, fixed iteration counts, checked pthread return values, destroyed mutex; no detached work.

    No writer is not the same as no bytes

    Observe EAGAIN on an empty nonblocking pipe, then drain buffered data after closing its final writer.

    Download pipes.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread pipes.c -o pipes
timeout 5s ./pipes

    Expected: EAGAIN with live writer, XYZ after writer close, then zero for a positive-size read.

    Change one condition: Duplicate the write end and retain it after closing the original. Predict the last read and close the duplicate to restore EOF.

    Cleanup and assumptions: One pipe, three bytes, nonblocking reader; both ends close. No packet-mode or multiple-reader behavior.

    Stream half-close

    Send six bytes over a local stream socketpair, half-close one direction, then send a reply in the other.

    Download sockets.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread sockets.c -o sockets
timeout 5s ./sockets

    Expected: All six bytes precede receive EOF; reverse reply OK still succeeds.

    Change one condition: Use a two-byte receive buffer and track framing independently from read boundaries. Explain why this does not exercise TCP TIME_WAIT.

    Cleanup and assumptions: AF_UNIX socketpair, no network listener, six-byte payload and two-byte reply; both sockets close.

    Partial drain after an edge

    Register a nonblocking pipe with epoll edge notification, partially read it, then drain remaining bytes to EAGAIN.

    Download readiness.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread readiness.c -o readiness
timeout 5s ./readiness

    Expected: First event arrives; three bytes read, then five remain. Second zero-timeout poll is printed rather than used as a reservation.

    Change one condition: Compare level-triggered registration. Keep the actual read loop nonblocking in both cases.

    Cleanup and assumptions: Linux epoll and pipe2; eight bytes; finite waits and watchdog; all descriptors close.

    Timer expiration counter

    Arm a 20 ms monotonic one-shot timerfd and consume its 64-bit expiration count.

    Download timers.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread timers.c -o timers

    Expected: Count one; actual scheduling delay is not asserted or promised.

    Change one condition: Use a bounded periodic timer and delay reads. Explain why the counter can exceed one even though one read completes.

    Cleanup and assumptions: Linux timerfd, one timer, one read, no wall-clock modification; descriptor closes.

    Canonical input on a private PTY

    Write a partial line at the master, observe an unreadable slave, then complete the line with newline.

    Download pty.c · Download common.h

    cc -std=c11 -Wall -Wextra -Werror -O2 -pthread pty.c -o pty
timeout 5s ./pty

    Expected: abc remains buffered until newline; slave returns abc plus newline. Echo is explicitly disabled.

    Change one condition: Set noncanonical mode with explicit VMIN and VTIME and predict readiness. Keep this private PTY separate from the user's interactive terminal.

    Cleanup and assumptions: Linux devpts support, no shell child or controlling-terminal acquisition; both handles close and private PTY disappears.
